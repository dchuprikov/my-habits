# Мои привычки — PWA v4

## Изменения v4

- Более компактный интерфейс на телефоне:
  - уменьшены заголовки, названия привычек и подписи;
  - уменьшена высота строк;
  - недельная сетка сжата, чтобы гораздо больше помещалось на одном экране;
  - диалоги и кнопки адаптированы под узкий экран и больше не должны вылезать за границы.
- В режиме **День** появился переключатель **✈️ Вне режима**.
- Для любой даты можно:
  - исключить **весь день**;
  - исключить только **отдельные привычки**.
- Исключенные привычки:
  - не входят в счетчики дня и недели;
  - не считаются пропущенными;
  - не разрывают серии;
  - в недельной таблице отмечаются `×`.
- Старые данные v3 совместимы: при обновлении история и отметки сохраняются в `localStorage`.

## Обновление GitHub Pages

Загрузи файлы из этого архива в корень репозитория `my-habits` поверх старых и нажми **Commit changes**.
Особенно важны `index.html` и `sw.js`.

После обновления GitHub Pages может потребоваться 1–2 минуты. Если на телефоне остается старая версия, полностью закрой PWA и открой снова; при необходимости обнови страницу в Chrome.
