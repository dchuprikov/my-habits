# Мои привычки — PWA

Готовый спокойный недельный трекер привычек.

## Что уже умеет

- недельная сетка ПН–ВС;
- галочки по дням;
- режимы:
  - каждый день;
  - только будни;
  - только выходные;
  - конкретные дни недели;
  - N раз за неделю;
- привычки, не действующие в конкретный день, показываются как «—» и не входят в статистику;
- группы привычек;
- сворачивание групп;
- добавление, редактирование и удаление привычек;
- просмотр прошлых и следующих недель;
- локальное хранение данных на устройстве;
- экспорт/импорт резервной копии JSON;
- офлайн-режим после первого открытия;
- установка на главный экран как PWA.

## Как запустить локально на компьютере

Service Worker не работает при открытии index.html как file://.
Для полноценной проверки запусти локальный сервер, например:

    python -m http.server 8000

После этого открой:

    http://localhost:8000

## Как поставить на телефон как приложение

Самый простой вариант — GitHub Pages:

1. Создай репозиторий на GitHub.
2. Загрузи в корень все файлы из этой папки.
3. В Settings → Pages включи публикацию из ветки main, папка /(root).
4. Открой получившийся HTTPS-адрес на Honor.
5. В Chrome / браузере выбери «Добавить на главный экран» или «Установить приложение».

Важно: данные хранятся локально в браузере. На другом устройстве они сами не появятся.
Для переноса используй Экспорт / Импорт.
