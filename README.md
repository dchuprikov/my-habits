# Мои привычки — PWA v3

## Что добавлено

- Явный переключатель **День / Неделя**.
- **День**: видны только привычки, действующие в выбранную дату, плюс мягкие недельные цели.
- **Неделя**: таблица ПН–ВС и общий недельный счетчик.
- В недельном режиме можно нажать на дату — откроется именно этот день.
- У каждой привычки есть кнопка **i** со статистикой:
  - текущая серия;
  - лучшая серия;
  - сколько дней всего отмечено;
  - процент выполнения последних 30 плановых дней;
  - история последних 28 дней.
- Для привычек «N раз в неделю» серия считается в неделях.
- Будни/выходные, когда привычка не запланирована, не считаются пропусками и не ломают серию.

## Как обновить GitHub Pages

В репозитории `my-habits` загрузи файлы из этого архива поверх старых и нажми **Commit changes**.
Особенно важны `index.html` и `sw.js`.

GitHub Pages обновится автоматически. Данные привычек хранятся в браузере (`localStorage`), поэтому обычное обновление файлов их не удаляет.
