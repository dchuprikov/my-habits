# Мои привычки — PWA v5.2

### Новое
- Привычки можно перемещать вверх и вниз **внутри своей группы**.
- Открой привычку через `⋮` → внизу появились кнопки **↑ Выше** и **↓ Ниже**.
- Порядок сохраняется автоматически.
- Полностью обновлена иконка приложения: мягкая синяя плитка, белая карточка и зеленая галочка.
- Иконка настроена как `maskable`, поэтому Honor/Android должен аккуратнее вписывать ее в системную форму ярлыка.

### Как обновить
1. Распакуй архив.
2. GitHub → `my-habits` → **Add file → Upload files**.
3. Загрузи все файлы поверх существующих → **Commit changes**.
4. Подожди 1–2 минуты и полностью перезапусти PWA.

### Если новая иконка не появилась
Android часто кэширует иконки PWA. Сначала сделай **Экспорт** данных в настройках приложения для подстраховки. Затем удали установленное PWA/ярлык, открой сайт заново в Chrome и снова выбери **Установить приложение**.
