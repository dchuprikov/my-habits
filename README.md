# Мои привычки — PWA v4.2

Изменения:
- недельная таблица оставляет больше места под название привычки;
- название привычки больше не дробится по буквам;
- текст занимает верхнюю часть левой ячейки (до 2 строк);
- иконка привычки, `i` и `⋮` расположены отдельной строкой под названием;
- все 7 дней недели по-прежнему помещаются на экране.

Обновление:
1. В GitHub `my-habits` выбери **Add file → Upload files**.
2. Загрузи файлы из архива поверх старых.
3. Нажми **Commit changes**.
4. Через 1–2 минуты полностью закрой PWA на Honor и открой снова.

История и галочки остаются в localStorage и при обновлении не удаляются.
