# Мои привычки — PWA v5.1

Финальная полировка интерфейса.

### Что изменено
- в режиме **День** верхний заголовок теперь показывает только прогресс: `0 из 9 · 0%`;
- дата остается только в календарной карточке, без дублирования;
- **✈️ Вне режима** превращено в тихую вторичную команду без отдельной подписи;
- плавающая кнопка `+` уменьшена до 44×44 и сильнее прижата к правому нижнему углу;
- при прокрутке `+` слегка становится прозрачной и возвращается после остановки;
- в недельном режиме `i` и `⋮` уменьшены, чтобы название привычки было главным;
- добавлен дополнительный нижний отступ, чтобы FAB не закрывала последнюю строку.

Все данные и логика v5 сохранены.
