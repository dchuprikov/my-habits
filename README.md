# Мои привычки — PWA v4.1

Изменения:
- группа **«Доходы»** переименована в **«День»**;
- для уже установленной версии название обновится автоматически, если оно ещё было стандартным «Доходы»;
- недельная таблица на телефоне сжата так, чтобы помещались все 7 дней, включая воскресенье;
- дополнительно ограничено расширение колонки с названиями привычек.

Обновление:
1. В GitHub `my-habits` выбери **Add file → Upload files**.
2. Загрузи файлы из архива поверх старых.
3. Нажми **Commit changes**.
4. Подожди 1–2 минуты и полностью перезапусти PWA на Honor.

Отметки и история хранятся в localStorage и при обычном обновлении файлов не удаляются.
