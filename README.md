# Мои привычки — PWA v5

В этой версии сделан полный визуальный polish без изменения логики трекера.

### Что изменилось
- единая спокойная визуальная система: мягкий фон, чистые карточки, тонкие границы и аккуратные тени;
- более «дорогой» сегментированный переключатель День / Неделя;
- более выразительный сегодняшний день и выбранная дата;
- счетчики групп оформлены компактными pill-бейджами;
- строки привычек стали чище и легче читать;
- выполненные привычки имеют приятное зеленое состояние вместо тяжелой заливки;
- кнопки, формы и диалоги приведены к одной системе размеров и скруглений;
- FAB-кнопка не конфликтует с safe-area телефона;
- добавлена небольшая тактильная вибрация при отметке привычки, если браузер ее поддерживает;
- сохранены режим «Вне режима», статистика, День / Неделя, будни / выходные и недельные цели.

### Обновление
1. Распакуй архив.
2. В GitHub `my-habits` → **Add file → Upload files**.
3. Загрузи файлы поверх существующих → **Commit changes**.
4. Через 1–2 минуты полностью закрой PWA на Honor и открой снова.

Все данные продолжают храниться в `localStorage`, поэтому обычное обновление кода их не удаляет.
